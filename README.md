# Controls — Forecasting Repository

Shared forecasting files for PrehabGuys. Use this repo to track revenue forecasts, overlay models, and methodology documentation.

## Structure

```
2026 Q2/
  combined-q2-2026-overlay.md   # Q2 2026 combined forecast overlay
METHODOLOGY.md                  # How the forecasting model works
```

## Quick Reference

To grab the latest files:
```
git pull origin main
```

To open with Claude Code:
```
cd ~/code/controls
claude
```

Then ask Claude things like:
- *read the Q2 combined overlay and summarize the key numbers*
- *what are the Floor, Target, and Stretch revenue numbers for Q2?*
- *show me what changed in the last update*
